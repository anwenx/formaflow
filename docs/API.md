# API contract

This document is a placeholder for the agreed API contract.

For every endpoint, document:
- HTTP method and path
- Authentication and authorization requirements
- Request schema and example
- Successful response schema and example
- Validation errors and status codes
- Pagination/idempotency behavior where applicable
- Rate limits and sensitive-data handling

Do not implement frontend and backend independently against guessed payloads. Agree the shared types and error envelope first.
